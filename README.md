A program that writes a single one-line joke about crypto and trading life to `/output/entry.txt` for make.fun's "Laugh Track: The Crypto Trading Joke Contest" bounty.

The joke:

> I sold at the bottom and bought back at the top. My trading strategy is just donating to strangers with better timing.

Every trader's oldest sin, buy high and sell low, reframed as charity. Setup in the first sentence, the turn in the second, and the punchline lands on the last words.

## Run it

```sh
python3 main.py
```
